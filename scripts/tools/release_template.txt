# WHY A SCRIPT
# Omnis can read and change its own classes, methods, variables and objects from code, and save them.
# A release can therefore be BUILT instead of prepared by hand: from the same working library, every
# time the same way, and every step reads back what it did. Nothing here is special to this library;
# each step is one pattern you can turn to other parts of a release.
#
# WHAT IT DOES, IN THIS ORDER
#  0  CHOOSE   the library named in the ADAPT HERE line must be OPEN; the version is set there too.
#  1  PLACES   texts that must (or must not) stand in methods of the library: the version where the
#              library reports it, a changelog heading for it, no leftover 'Unreleased' section.
#  2  FILES    the files to ship beside the library lie in execInput/release_template/ beside the
#              Executor. The first run makes that folder and stops with the list of files to lay in.
#  3  ASK      TRIAL or REAL, a No/Yes message; No, the default, builds a TRIAL. In a TRIAL a failed
#              check of 1 or 2 only warns; in a REAL build it stops before anything is copied.
#  4  COPY     the FILE of the library is copied to execRelease/<library>/<version>/ beside the
#              Executor (a TRIAL to <version>-trial/) and opened as <library>_Release, WITHOUT its
#              startup task. Your library itself is never written. Unsaved changes are not in the
#              copy: save first. Copying the file of an open library is measured on macOS only.
#  5  DATA     class variables that hold the developer's data are removed, or their $userinfo emptied.
#  6  NEUTRAL  methods that must not ship as they are (a playground, a test) get a neutral text;
#              their local variables stay.
#  7  CLASSES  the classes of the copy against the list you expect; reports, removes nothing.
#  8  VERSION  every class gets the release version in its $version.
#  9  LINES    every line of every class method and of every method of a window object is walked:
#              a line marked as a developer line is commented, a commented line marked as a release
#              line is armed, and the lines that stay active are searched for forbidden texts.
# 10  DISK     every class is saved, the copy closed and opened again FROM DISK, and steps 5 to 9 are
#              read back there. What is reported as done is what the file holds.
# 11  SHIP     the files of step 2 are copied beside the library copy.
# 12  JSON     the copy is exported as JSON into json/ in the same folder, every error row listed.
# 13  CLOSE    the copy is closed on every path after it was opened; the last line says whether the
#              copy is a release or INCOMPLETE.
#
# THE MARKERS (step 9)
# A developer line ends in ' ## @DEV' and is active in your working library:
#     OK message Debug {[lValue]} ## @DEV           ->  # OK message Debug {[lValue]} ## @DEV
# A release line is commented in your working library and ends in ' ## @RELEASE':
#     # Calculate iMode as 'release' ## @RELEASE      ->  Calculate iMode as 'release' ## @RELEASE
# The marker is an ordinary end-of-line comment; Omnis keeps it. Choose your own markers in step 9.
#
# WHAT ELSE CAN BE DONE THE SAME WAY (each is a few lines in the shape of the steps below)
# - remove test classes from the copy: classRef.$classes.$remove(...), then nothing to save.
# - rename text in every method of a class: classRef.$findandreplace(find,replace) - close its design
#   editors and the Find and Replace dialog first, and set $root.$prefs.$alloweditifnotcheckedout.
# - write a property of a class or an object: a window title, a tooltip, the text of a button

#   its direct children, tools.$collectObjects collects them all.
# - check the superclasses: every classRef.$superclass of the form Lib.Class must lie in an open library.
# - rebuild the library from its JSON tree: $root.$importjson(jsonFolder,newLibPath) writes a new file
#   without the dead space a library collects. A tree with a broken line does not import.
# - NOT possible: $prefs.$defaultname of a library cannot be assigned by notation (25207).
#
# BEFORE YOU RUN IT
# - Save your library. Open every library its code names, and every library holding a superclass.
# - Switch off "Break if error": a line refused in step 9 raises an error and the run goes on.
# - The six [danger] lines and the dialog: see the top of this script. Steps 5 and 6 ask (stage A);

# ====== 5  DATA — the developer's data out of the copy
# A library carries data, not only code. The VALUE of a class variable is saved with its class. Every
# variable definition, every class and the library itself have a property $userinfo that code can fill
# with any value - a text, a list, a row - and that is saved as well. A settings class therefore ends
# up holding what the developer stored last: a private path, the last login, a test server, a log.
# All of it ships inside the .lbs file unless the release removes it. In MyLib this is oSettings;
# its method $about says the same from the inside.
# 'remove' deletes the definition, value and $userinfo with it; 'clear' keeps the variable and empties
# its $userinfo. Both act on the release COPY only.
# CAUTION: a removed variable that code still names turns those lines into #???. They still compile
# as text, but the JSON export of step 12 fails on them (23470). Remove only variables that serve as
# a store; empty the others.
## ADAPT HERE: class, class variable, 'remove' or 'clear'
Do list.$define()
Do list.$cols.$add('cls',kCharacter,kSimplechar,255)
Do list.$cols.$add('var',kCharacter,kSimplechar,255)
Do list.$cols.$add('how',kCharacter,kSimplechar,20)
Do list.$add('oSettings','cDevPath','remove')
Do list.$add('oSettings','cLastLogin','clear')

Calculate count as 0 ## rows done

   Set reference classRef to ref2.$classes.$findname(list.cls)
   If isclear(classRef)
      Calculate result as con(result,'[data    ]   FAIL ',list.cls,' NOT found in the copy',kCr)
   Else
      Set reference ref to classRef.$cvardefs.$findname(list.var)
      If isclear(ref)
         Calculate result as con(result,'[data    ]   FAIL ',list.cls,'.',list.var,' NOT found in the copy',kCr)
      Else If list.how='remove'
         Do classRef.$cvardefs.$remove(classRef.$cvardefs.$findname(list.var).$ref)
         If isclear(classRef.$cvardefs.$findname(list.var))
            Calculate count as count+1
            Calculate vars.cvarsRemoved as vars.cvarsRemoved+1
            Calculate result as con(result,'[data    ]   ',list.cls,'.',list.var,' removed',kCr)
         Else
            Calculate result as con(result,'[data    ]   FAIL ',list.cls,'.',list.var,' is still there after $remove',kCr)
         End If
      Else If list.how='clear'
         Do ref.$userinfo.$assign('') Returns flag2
         If flag2&(len(classRef.$cvardefs.$findname(list.var).$userinfo)=0)
            Calculate count as count+1
            Calculate result as con(result,'[data    ]   ',list.cls,'.',list.var,' $userinfo emptied',kCr)
         Else
            Calculate result as con(result,'[data    ]   FAIL ',list.cls,'.',list.var,' $userinfo NOT emptied',kCr)
         End If
      Else
         Calculate result as con(result,'[data    ]   FAIL ',list.cls,'.',list.var,': ''',list.how,''' is neither remove nor clear',kCr)
      End If
   End If
End For
Calculate vars.ok as vars.ok&(count=list.$linecount)

# ====== 9  LINES — developer lines out, release lines in, forbidden texts searched
# Pass 1 walks the copy in memory and changes it. Then every class is saved, the copy closed and
# opened again FROM DISK, and pass 2 walks it once more and only counts (step 10).
# Walked are the class methods of every class with methods, and the methods of every object of a
# window. Reports, menus, toolbars and remote forms have objects with methods as well: walk them the
# same way, through classRef.$objs.
# A forbidden text is searched in the lines that stay ACTIVE after the markers are applied, so
# '# Breakpoint ## @DEV' is no hit. A runtime ignores Breakpoint; a tester with a design version
# stops there.
## ADAPT HERE: the two markers, and the forbidden texts (found in any case)
Calculate vars.dev as con(' #','# @DEV') ## built so no double hash stands in a literal of this script
Calculate vars.rel as con(' #','# @RELEASE')
Do list2.$define()
Do list2.$cols.$add('txt',kCharacter,kSimplechar,255)
Do list2.$add('Breakpoint')
Do list2.$add('Send to trace log')

For n3 from 1 to 2 step 1
   If n3=2
      # ====== 10  DISK — save every class, close, open again from disk
      # Notation changes live in memory until the class is saved; Save class writes only what is pending.
      Do ref2.$classes.$makelist($ref.$name,$ref.$classtype*1) Returns list
      Calculate count as 0
      For list.$line from 1 to list.$linecount step 1
         If (list.C2=kSystemtable)|(list.C2=kFolder)
         Else
            Save class [con(name,'.',list.C1)]
            Calculate count as count+1
         End If
      End For
      Close library [name]
      Open library (Do not close others,Do not open startup task) [name3],[name]
      Set reference ref2 to $root.$libs.$findname(name)
      Calculate result as con(result,'[disk    ]   ',count,' class(es) saved; the copy opened again from disk ',pick(isclear(ref2),'- ok','- FAILED, nothing read back'),kCr)
      If isclear(ref2)
         Calculate vars.ok as kFalse
         Break to end of loop
      End If
   End If
   Set reference classRef to ref2.$classes.$first()
   While not(isclear(classRef))
      Calculate count as classRef.$classtype*1
      Calculate text as classRef.$name
      # --- the methods of this class, collected right before its lines are walked
      Do list.$define()
      Do list.$cols.$add('path',kCharacter,kSimplechar,100000000)
      Do list.$cols.$add('orow',kInteger,k32bitint) ## 0 = a class method, else the row of its object in list3
      Do list.$cols.$add('mname',kCharacter,kSimplechar,255)
      If count=kWindow*1|count=kRemoteForm*1|count=kReport*1|count=kMenu*1|count=kToolbar*1|count=kTask*1|count=kRemoteTask*1|count=kObjectclass*1|count=kTable*1|count=kCode*1
         Set reference methodRef to classRef.$methods.$first()
         While not(isclear(methodRef))
            Do list.$add(methodRef.$name,0,methodRef.$name)
            Set reference methodRef to classRef.$methods.$next(methodRef)
         End While
      End If
      # --- the objects of a window, at every depth: tools.$collectObjects walks $objs and $bobjs
      Do list3.$define()
      If count=kWindow*1
         Do tools.$collectObjects(classRef.$ref,list3) Returns n
      End If
      For n from 1 to list3.$linecount step 1
         If not(list3.[n].isBkgnd) ## a background object carries no methods
            Set reference objRef to list3.[n].objRef().$ref
            Calculate text3 as list3.[n].objPath
            If len(list3.[n].objName)=0
               Calculate text3 as objRef.$fullname ## a nameless object: its $fullname ends in type and ident
               Calculate text3 as mid(text3,rpos('.',text3)+1,len(text3))
            End If
            Set reference methodRef to objRef.$methods.$first()
            While not(isclear(methodRef))
               Do list.$add(con(text3,'.',methodRef.$name),n,methodRef.$name)
               Set reference methodRef to objRef.$methods.$next(methodRef)
            End While
         End If
      End For
      # --- every line of every method of this class
      For n from 1 to list.$linecount step 1
         # found again by the row of its object and its name, right before its lines are walked
         Calculate n2 as list.[n].orow
         If n2=0
            Set reference methodRef to classRef.$methods.$findname(list.[n].mname)
         Else
            Set reference objRef to list3.[n2].objRef().$ref
            Set reference methodRef to objRef.$methods.$findname(list.[n].mname)
         End If
         If isclear(methodRef)
            If n3=1
               Calculate vars.unreached as vars.unreached+1
               Calculate result as con(result,'[unreach ]   ',text,' / ',list.[n].path,' - its lines were NOT walked',kCr)
            End If
            Jump to start of loop
         End If
         Calculate n2 as 0 ## the line number
         Set reference ref to methodRef.$methodlines.$first()
         While not(isclear(ref))
            Calculate n2 as n2+1
            Calculate text2 as ref.$text
            If n3=1
               Calculate vars.lines1 as vars.lines1+1
               If (pos(vars.dev,text2)>0)&(left(trim(text2),1)<>'#')
                  Do ref.$text.$assign(con('# ',text2)) Returns flag2
                  If flag2
                     Calculate vars.devDone as vars.devDone+1
                     Calculate result as con(result,'[dev     ]   ',text,' / ',list.[n].path,' / line ',n2,' commented',kCr)
                  Else
                     Calculate vars.refused as vars.refused+1
                     Calculate result as con(result,'[dev     ]   REFUSED ',text,' / ',list.[n].path,' / line ',n2,': ',text2,kCr)
                  End If
               Else If (pos(vars.rel,text2)>0)&(left(trim(text2),2)='# ')
                  Do ref.$text.$assign(mid(trim(text2),3,len(text2))) Returns flag2
                  If flag2
                     Calculate vars.relDone as vars.relDone+1
                     Calculate result as con(result,'[release ]   ',text,' / ',list.[n].path,' / line ',n2,' armed',kCr)
                  Else
                     Calculate vars.refused as vars.refused+1
                     Calculate result as con(result,'[release ]   REFUSED ',text,' / ',list.[n].path,' / line ',n2,' - it does not compile in the copy: ',text2,kCr)
                  End If
               End If
               Calculate text2 as ref.$text ## what stands now
            Else
               Calculate vars.lines2 as vars.lines2+1
            End If
            # --- in both passes: what stands now
            If left(trim(text2),1)='#'
               If n3=2
                  Calculate vars.relLeft as vars.relLeft+(pos(vars.rel,text2)>0)
               End If
            Else
               If n3=2
                  Calculate vars.devLeft as vars.devLeft+(pos(vars.dev,text2)>0)
               End If
               For list2.$line from 1 to list2.$linecount step 1
                  If pos(low(list2.txt),low(text2))>0
                     If n3=1
                        Calculate vars.forbid1 as vars.forbid1+1
                        Calculate result as con(result,'[forbid  ]   ',text,' / ',list.[n].path,' / line ',n2,': ',text2,kCr)
                     Else
                        Calculate vars.forbid2 as vars.forbid2+1
                     End If
                  End If
               End For
            End If
            Set reference ref to methodRef.$methodlines.$next(ref)
         End While
      End For
      Set reference classRef to ref2.$classes.$next(classRef)
   End While
   If n3=1
      Calculate result as con(result,'[lines   ]   ',vars.lines1,' line(s) walked: ',vars.devDone,' developer line(s) commented, ',vars.relDone,' release line(s) armed, ',vars.refused,' refused, ',vars.forbid1,' forbidden, ',vars.unreached,' method(s) not reached',kCr)
   End If
End For
Calculate vars.ok as vars.ok&(vars.refused=0)&(vars.unreached=0)
If vars.forbid1>0
   If flag3
      Calculate result as con(result,'[forbid  ]   ',vars.forbid1,' forbidden line(s) - TRIAL, going on',kCr)
   Else
      Calculate vars.ok as kFalse
      Calculate result as con(result,'[forbid  ]   ',vars.forbid1,' forbidden line(s) - this copy is NOT a release',kCr)
   End If

# ====== 10  DISK — steps 5 to 9 read back from the file
If not(isclear(ref2))

   Calculate flag2 as (vars.lines2=vars.lines1)&(vars.devLeft=0)&(vars.relLeft=0)&(vars.forbid2=vars.forbid1)

   Calculate result as con(result,'[disk    ]   lines ',vars.lines2,' (pass 1: ',vars.lines1,'), active developer lines ',vars.devLeft,', commented release lines ',vars.relLeft,', forbidden ',vars.forbid2,pick(flag2,' - NOT as in memory',' - as in memory'),kCr)
